# Roadzy — Autonomous Road Quality Monitoring

**Roadzy** is an autonomous robot vehicle designed to monitor and evaluate road conditions in real time. Using vibration sensors, accelerometers, and line-following technology, Roadzy collects data about road roughness, potholes, and other surface issues, helping cities and drivers make roads safer and smoother.

---

## 🚀 Features

- **Autonomous Navigation:** Follows road lines without human intervention.  
- **Real-Time Road Assessment:** Measures vibrations and surface quality to detect problem areas.  
- **Smart Map Visualization:** Interactive maps show sector-based road quality and the best routes.  
- **Actionable Insights:** Enables data-driven maintenance to reduce accidents and improve road safety.

## ⚡ Technology Stack

- **Frontend / Dashboard:** HTML, CSS, JavaScript  
- **Mapping & Routing:** Leaflet.js, Leaflet Routing Machine  
- **Sensors:** Accelerometer, Vibration Sensor, Line-Following Modules  
- **Communication:** WebSocket for real-time data streaming  

---

## 📌 Usage

1. Run the server.js server to stream sensor data from the robot.  
2. Open `index.html` in a browser to view the live dashboard and smart map.  
3. Select a route to see sector-based road quality and interact with the map.  

---

## 📈 Impact

Roadzy helps municipalities monitor road quality efficiently, reduces the risk of accidents, and enables data-driven maintenance planning, ultimately making roads safer for everyone.
